This folder contains a **new beginner-friendly local alternative** that communicates with Ollama `qwen3:1.7b` using the local API. The original curriculum teaches Strands and LangGraph; the added local notebook **does not claim** to reproduce those frameworks.

Python 3.12, JupyterLab, Ollama running locally and `ollama pull qwen3:1.7b`. No AWS required.
