# Adding Real Results Safely

The project includes **source notebooks only**, not the files generated when they were executed on the learner's Windows PC.

1. In JupyterLab, locate the authentic `section4_*`, `section5_*`, `section6_*` and `section7_*` report files created by successful lab runs.
2. Download and read these reports **locally**.
3. Remove usernames, home paths, credentials, API keys, personal data, account IDs and company-confidential information.
4. Put verified sanitised copies into an `evidence/` directory.
5. Only then use Git to commit them.

Do not convert example outputs into purported live test results. The initial portfolio intentionally has **no evidence folder**.
