# GitHub Publishing and Repository Location

The portfolio in this conversation has been added to the learner's existing public course repository, inside the isolated folder:

```text
dashrathdj91-hue/weekend-sessions/local-ollama-portfolio/
```

Original course files in `weekend-sessions` are kept separate. The source notebooks do **not** contain local execution outputs.

A copy can also be published later as a standalone **private** repository using Git for Windows and GitHub CLI. Review all files for credentials before making such a repository public. The optional PowerShell helper `publish_to_github.ps1` is only for creating a standalone repository; it should not be run against the existing course repository.

For updates to this folder, commit under `local-ollama-portfolio/` to avoid modifying upstream course materials.
